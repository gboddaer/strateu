# Goal Prompt

Make the Kolibri prompt prefill cache work: an extending request (a coding agent's next turn) must reuse the held KV prefix correctly, report it honestly, and the win must be measured and published.

Plan: docs/superpowers/plans/2026-10-25-kolibri-prefix-reuse.md (spec: docs/superpowers/specs/2026-10-25-kolibri-prefix-reuse-design.md). Execution: Native (implement in this session, one fresh reviewer on the whole branch at the end).

Root cause already measured on this box (2026-10-25): in src/kolibri/kolibri_engine.cu serve(), `fresh` is a COUNT of new tokens but both prefill loops compare it against a POSITION, so with reuse > 0 zero tokens are fed to the model; a 580-token extending request reported `reused 516, read 64, prompt_ms 0.0` and answered from KV that never saw the new turn.

Ordered stages, each ending in a green gate and a commit:

1. Write tools/kolibri/reuse_gate.sh RED against the current binary, with committed fixtures reuse_ids3k.txt (3,000 ids, past the 513-row sliding ring) and reuse_ids_tail64.txt. Stages: (1) bitwise - cold full-prompt arm vs prefix-then-extend arm must generate identical ids; (1b) one-token tail must match cold with prompt_read 0; (2) accounting - reused==3000, prompt_read==64, prompt_ms > 0; (3) negative - a diverging prefix must reset (reused 0). Keep the red output as evidence the gate is not vacuous.
2. Fix the bounds in both the chunked and plain prefill paths to position arithmetic (feed positions reuse .. ids.size()-2). Gate: reuse gate green AND bash tools/kolibri/pf_gate.sh check still prints oracle PASS (BITWISE PASS) against the unchanged recorded ids - the cold path must not move.
3. Print `RESUME <reuse>` before the first PP line when reuse > 0 (the contract serve/server.py:1934 and src/program/generate.cpp:11225 already keep), make PP positions absolute from token 0 with total = ids.size(), teach tools/kolibri/bench.py to skip RESUME and rate over read tokens, and add a serve/test_request_accounting.py case asserting cache_n 516 / prompt_n 64.
4. A request cancelled with STOP must not leave `live` claiming KV it never built; add the gate stage first, then make it true.
5. Wire the reuse gate into pf_gate.sh as its own stage; run the full gate on the default path and with STRATA_KOLIBRI_PF_PARTIAL=1; build the other backend (HIP) or record in the commit and findings log exactly what the AMD box still owes.
6. Price it: tools/kolibri/agent_bench.py (N turns of growing context, per-turn reused/read/prompt_ms/tok/s and total wall), measured after AND before (pre-fix rebuild), two runs each, with numactl node 1, load and --cpu-threads printed. Record in docs/findings-log.md first, then docs/published-figures.md rows, then the pages only if a quoted figure changes; finish with python3 tools/kolibri/check_published_figures.py clean.
